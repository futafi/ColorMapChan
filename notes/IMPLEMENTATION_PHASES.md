## 開発ルール

### Git管理
- Semantic Versioning (x.y.z)
- 細かい単位でのコミット
- コミットメッセージ：`[Phase X.Y] 実装内容の簡潔な説明`

### 品質管理
- 各Phase完了時に動作確認
- GitHub Actions自動テスト必須
- exe動作確認必須

### 優先順位
1. 動作することが最優先
2. テスト可能性確保
3. シンプルな実装
4. 個人用途のため完璧性は求めない
